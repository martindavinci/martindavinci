## Tools

- **[MDV Tools](https://martindavinci.github.io/mdv-tools/)** — web tools that each do one job. Nothing leaves
  your device: no requests once a page has loaded, no account, works offline.
  · [source](https://github.com/martindavinci/mdv-tools)

## Demos

- **[The Scholar Cat Cabinet](https://martindavinci.github.io/mdv-demo-arcade/)** — 22+ one-button arcade games
  with the same cat in each. Space or tap is the only control.
  · [source](https://github.com/martindavinci/mdv-demo-arcade)
- **[Borghi in diorama](https://martindavinci.github.io/mdv-demo-diorama/)** — four pixel-art villages to walk
  around. No 3D models: every sprite pixel is extruded into depth. In Italian.
  · [source](https://github.com/martindavinci/mdv-demo-diorama)
