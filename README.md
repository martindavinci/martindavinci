# Martin DaVinci

![](res/landscape.png)

*Knowledge has no limits.*

## Tools

- **[MDV Tools](https://martindavinci.github.io/mdv-tools/)** — web tools that each do one job. Nothing leaves
  your device: no requests once a page has loaded, no account, works offline.

## Demos

- **[The Scholar Cat Cabinet](https://martindavinci.github.io/mdv-demo-arcade/)** — 22+ one-button arcade games
  with the same cat in each. Space or tap is the only control.
- **[Borghi in diorama](https://martindavinci.github.io/mdv-demo-diorama/)** — 30+ pixel-art villages to walk
  around. No 3D models: every sprite pixel is extruded into depth. In Italian.
- **[The Scholar Cat](https://martindavinci.github.io/mdv-demo-rpg-cat/)** — a small retro action-RPG in a 2.5D
  pixel diorama: Folio, the library cat, goes after the torn pages of an old codex. Keyboard, gamepad or touch; in
  English and Italian.
- **[Marble Loop](https://martindavinci.github.io/mdv-demo-marble-loop/)** — a marble bounces down xylophone keys
  set in a white wall and plays Mozart, Offenbach and Rossini, in a 45-second loop that never ends. Tap for sound.
