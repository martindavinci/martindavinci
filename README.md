<td width="75%" valign="top"><b><a href="https://github.com/martindavinci/mdv-second-brain">mdv-second-brain</a></b><br>An AI skill for Claude Code and Codex, installed as a plugin: persistent project memory for coding agents, kept as an Obsidian vault for each workspace. While you work, the agent records what was done, why and what was learned (a Kanban board, living task and issue notes, daily checkpoints, distilled project knowledge, decisions and ideas), so the next session starts where the last one stopped. <td width="75%" valign="top"><b><a href="https://github.com/martindavinci/mdv-linux-kernel">mdv-linux-kernel</a></b><br>An AI skill for Claude Code and Codex that mentors people sending their first Linux kernel patches, with netdev in depth. It does not hide AI use: it asks for evidence tied to the exact code and follows each tree's own rules. Before anything goes out, it checks the patch for the signs of AI slop that maintainers look for (a vague changelog, a wrong <code>Fixes:</code> tag, needless churn), then asks you questions about it, so you only send what you understand. You sign off and send it yourself.</td>
